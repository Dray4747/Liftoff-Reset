Данная программа создана для **сброса настроек Liftoff** по файлу конфигурации (config.xml).

> [!IMPORTANT]
> **Для корректной работы вам необходимо:**
> 1. Установить Liftoff в **ЛЮБОМ** удобном месте. По умолчанию: C:\Liftoff\
> 2. Проверьте, что в папке находятся: `Liftoff.exe`,`Liftoff_Data`,`UnityCrashHandler64.exe` и `UnityPlayer.dll`.
> 3. Далее в папке `Liftoff_Data\Config` должен быть создан файл конфигурации **`config.xml`** с вашими настройками.
> **Рекомендуется** также скачать файл `frconfig.xml` для возможности восстановления файла `System.xml`.
> 4. Запустите скачанное приложение. При первом запуске будет создан файл конфигурации `config.ini` по пути `C:\Liftoff\Liftoff_Data\Config\`.
> Если вы **НЕ** изменяли путь по умолчанию к рабочей папке Liftoff и не переименовывали файлы, вы можете пропустить настройку.
> 5. Проверьте, нет ли ошибок или предупреждений в консоли. В случае корректной установки Liftoff запустится.

> [!WARNING]
> Программа может вызвать реакцию антивируса, хотя сама по себе не является вирусом. Некоторые антивирусы склонны относить файл к классам повышенного риска или хакерским инструментам. **Происходит удаление файла и помещение его в карантин.**
>
> **В случае проблем с антивирусом добавьте файл в исключения**, либо **отключите детектирование PUA** (потенциально нежелательных приложений). Например, в Kaspersky есть галочка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда".
> 
> При аккуратной и правильной настройке исключений – рекомендуется настроить исключение, но если вы не до конца понимаете, что делаете, – рекомендуется отключить детект PUA.

> [!TIP]
> В случае обнаружения багов, недочетов, идей, пожалуйста сообщайте [**здесь**](https://github.com/Dray4747/Liftoff-Reset/issues/new)
## Описание config.ini
Файл конфигурации `config.ini` содержит следующие настройки:
- `debug`
  - Включает/выключает режим отладки. Принимает значения `true` или `false`.
  - По умолчанию: `false`
- `nhcolor`
  - Задает путь к файлу [nhcolor](https://nhutils.ru/blog/nhcolor/). **Не рекомендуется изменять.**
  - По умолчанию: `C:\Users\ПОЛЬЗОВАТЕЛЬ\AppData\nhcolor.exe`
- `Folder`
  - Задает путь к рабочей папке Liftoff. Полезно, если игра находится в другом расположении.
  - **ВАЖНО:** В конце пути **НЕ УКАЗЫВАЙТЕ** `\`. Это приведет к критической остановке программы. **Формат:** `C:\ВАШ_ПУТЬ`
  - По умолчанию: `C:\Liftoff`
- `Liftoff`
  - Задает название исполняемого файла Liftoff.
  - По умолчанию: `liftoff.exe`
- `config.xml`
  - Задает название файла конфигурации config.xml.
  - По умолчанию: `config.xml`
- `frconfig.xml`
  - Задает название файла восстановления конфигурации frconfig.xml.
  - По умолчанию: `frconfig.xml`
## Аргументы запуска
- `debug`
  - Включает режим отладки на текущую сессию.
